**解锁硬规则**：`本关 answeredCount >= questionCount` 即可进下一关；**不看正确率、不设分数门槛**（与「不用达标」一致）。过关后展示短反馈（见 JSON `stages[].clearFeedback`：可鼓励，**不得**点名本关某题正确选项原文），再回站点地图解锁下一站。

**流程一句话**：登录 → 嘉年华站点地图见已解锁站 → 进站答题 → 本关全部作答提交 → 过关反馈 → 解锁下一站 → … → 7 站完成 → 可交主卷看百分／可进挑战站（可跳过）。

**学生端呈现（老师）**：**一题一页**；每页顶区配「回忆当时学习画面与知识点」插图（第1–7课已学应用场景锚点），服务回忆／迁移、不泄答案；规格与字段见 `02`（生图优先 GPT、其次 Gemini；静态优先，必要时短循环轻量动图；Win7 Chrome 流畅）。

## 6 难度 0.75 说明与自检

- **目标**：约 ¾ 学生主卷可答对中等难度题；题干轻阅读（主卷多数 ≤65 字，挑战 ≤95 字）。计分用百分制、不设达标线。

- **要做**：新情境迁移；情境条件参与推理；SOLO 同质干扰；逆向排障／反例 ≥30%；题型多样少打字；**站点闯关推进、过关反馈清晰**。
