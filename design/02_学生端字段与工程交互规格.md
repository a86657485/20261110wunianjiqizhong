## 1 学生端不下发字段（硬性）

下发试卷／题目时，**不得**把下列字段送到学生浏览器（提交前白名单见 JSON `clientFieldsBeforeSubmit`）：

| 类别 | 字段 |
| --- | --- |
| 答案与解析 | `answer`、`accept`、`acceptAlternate`、`analysis` |
| 诊断内部 | `misconceptionMap`、`literacy`、`ctTags`（若仅教师大屏用可服务端保留） |
| 命题内部 | `remixFrom`、`remixNote`、`teacherNote`、`reverseDebug`、`difficultyEstimate`、**`goalIds`**（G/K/D 覆盖，学生端不下发） |
| 禁入题干文案 | `G1`/`K1`/`S1`/`E1`/`M1` 等代号、「循环体」 |

**允许下发**：`id`、`section`、`type`、`lesson`、`lessonTitle`、`prompt`、`options`、`left`、`right`、`slots`、`cards`、`diagram`（无答案）、`appRef`（场景名，如「分支岛」）、`interactionSpecKey`、`estimatedMinutes`、**`stage`／`stageId`／`stageName`**、回忆插图学生侧字段 **`recallSceneAnchor`／`recallCaption`／`recallImage`／`recallImageMaxWidthPx`／`recallImageAnimated`**、以及进度态 `currentStage`、`stagesCompleted`、`stageProgress`、`stageClearFeedback`（服务端按进度生成后下发）。**不下发** `recallImagePrompt`、`recallImageMotionNote`（服务端／教师包／美术用）。

判分只在服务端：学生提交作答后，服务端对照 `answer`／`accept`／`acceptAlternate` 评分；解析仅在**提交后**按校方策略是否回显（建议期中交卷后统一讲评再开解析）。

### 1.1 期中分层字段说明

- 期中用 **`section: "main" | "challenge"`** 区分主卷／挑战，**不强制**课堂短测那套 `tier` 字段。
- 每题另有闯关字段 `stage`／`stageId`／`stageName`（学生可见口语关名）。
- **`goalIds`** 仅服务端／教师版；不得进入 `clientFieldsBeforeSubmit` 白名单。

## 2 卷面外壳：算法嘉年华·站点通行证（轻量站点地图）

- 名称：**算法嘉年华·站点通行证**
- 形态：轻量**站点地图／站点推进**（7 站主卷＋ 1 可选挑战站）；过关有清晰短反馈
- 建议自拟组件名（示例，非强制实现）：`CarnivalMap`、`StageNode`、`StageClearBanner`、`StageProgressChip`
- **禁止**复用旧期末 `5qimokaoshi` 的地图组件名、布局结构、关卡资源命名

### 2.1 学生流程

1. 登录选班选姓名  
2. 进入 **嘉年华站点地图**：可见已解锁站（开场仅第 1 站「点心站·有序步骤」）  
3. 点进一站 → **一题一页**作答本关全部题目（顶区回忆插图＋题干＋交互＋本关进度；关内可回看改选，规则由服务端定义）  
4. **本关全部作答并提交本关** → 展示过关短反馈（`stageClearFeedback`）→ 回地图，下一站点亮  
5. 重复至主卷 7 站均「答完通关」  
6. 可**提交主卷**查看百分制得分；同时可进入 **加分挑战关**（可跳过）  
7. 结束页：主卷百分 ＋ 挑战加分（分开显示；可选综合分＝主卷＋加分）

### 2.1.1 一题一页布局＋回忆插图（老师 2026-11-09）

- **硬性**：**每一题一个页面**；关内按题翻页／下一题；**禁止**一屏多题并排或长页堆题。
- **页内结构建议（自上而下）**：
  1. **顶区回忆插图**＋短回忆标题（`recallCaption`）
  2. **题干**
  3. **选项／交互区**（单选／连线／流程图／应用操作）
  4. **本关进度**（如 `stageProgress` 芯片：已答／本关题数）＋站点关名
- 插图服务**回忆当时学习画面与知识点**（对应第1–7课已学课堂应用场景），利于回忆／迁移；**不泄答案**（禁止图中出现选项字母、正确答案黄框／唯一高亮、可直接指向正确选项的箭头）。
- **硬规则（老师）**：`recallCaption`／回忆插图／题干辅助语／操作引导／过关反馈**不得暗示正确选项或关键步骤**（禁止复述正确选项关键词、禁止直接点出「该选哪类原则／哪一步／哪侧出口」）；**未作答选项零高亮**；过关反馈可鼓励，但不得点名本关某题正确选项原文。

#### 回忆插图字段

| 字段 | 谁可见 | 说明 |
| --- | --- | --- |
| `recallSceneAnchor` | 学生可下发 | 应用场景锚点（如「生活处处有算法·机器人厨房」「算法小侦探」「汉诺塔实验室」「奇趣游园会」「生活算法站」「分支岛」「莲花山小交警」） |
| `recallCaption` | 学生可下发 | ≤20 字；只写「回想××站／××画面」；**禁止**正确选项 verbatim 与「要／应该／不能／必须＋考点结论」 |
| `recallImage` | 学生可下发 | 资源路径占位，如 `assets/recall/{id}.webp`；美术未出图前可为该占位路径或 `null`（实现任选，全班统一） |
| `recallImageMaxWidthPx` | 学生可下发 | 建议 **≤800**；优先 **webp／jpg**；体积宜小，面向 **Win7 Chrome** 流畅 |
| `recallImageAnimated` | 学生可下发（可选） | `true` 时本页可用短循环动图；**默认静态优先** |
| `recallImagePrompt` | **不下发学生**（serverOnly／教师包） | 生图提示词；2D 课堂友好、无文字墙、不出现选项字母／正确答案高亮 |
| `recallImageMotionNote` | **不下发学生**（serverOnly／教师包） | 可选；仅当需要动图时说明短循环要点（时长／循环内容）；**禁止**用动效泄露答案 |

#### 生图与动图策略

- **生图优先级**：优先 **GPT**，其次 **Gemini**；美术／生图由总管另派；本规格**只写字段与提示词，不生图**。
- **静态优先**；**必要时**可用动图（短循环 **webp／gif**）。
- 动图约束：宜**短、轻量**（建议循环 ≤1.5–2s、少色帧）；须在 Win7 Chrome 流畅；动效只增强「回忆氛围／待填空槽呼吸」等，**不得**闪烁正确选项或落点。

### 2.2 解锁规则（硬性 · 不因分数卡关）

| 项 | 规则 |
| --- | --- |
| 本关通关条件 | `answeredCount >= questionCount`（本关题全部有作答并提交） |
| 是否看正确率 | **否**；对错不影响解锁下一关 |
| 是否设分数／达标门槛 | **否**（`passLine` 保持 `null`；不设 passLineSuggestion） |
| 第 1 关 | 开场即解锁 |
| 第 2–7 关 | 上一关通关（答完）后解锁 |
| 挑战关 | 主卷 7 关全部答完后解锁；**可跳过**；只加分 |
| 主卷交卷 | 7 关全部答完后方可提交主卷换算百分（首答锁定） |

> 与老师「不用达标」一致：**闯关推进看「是否答完」，不看「是否答对」**。

### 2.3 计时

- 显示约 **30 分钟**建议用时（可正计时）
- 到时仍允许交卷，**不强制锁死**（待老师确认）

### 2.4 首答／最近／历史

- 主卷百分只认**首次整卷提交**（`firstSubmitMain`）
- 重做写入最近／历史，不改首答百分
- 挑战加分认挑战关首次提交（每对 +2，满分 +10）（老师已确认锁定）。

## 4 交互规格（按 `interactionSpecKey`）

### 4.1 `single_choice`（单选）

- 展示：题干＋4 个选项按钮（A–D 或无字母纯文案按钮）
- 操作：点选一项；再次点可改选（本关／交卷前，按服务端规则）
- 提交值：选项全文或稳定 `optionId`（与 JSON `options` 下标／文案一致）
- 判分：与 `answer` **选项全文**字符串全等（期中禁止用整数下标作 `answer`）

### 4.2 `matching`（连线）

- 左栏点选连右栏；一对一；交卷前可改
- 判分：映射与 `answer` 对象一致

### 4.3 `flowchart_op`／`app_op`

- 点选优先（卡片入槽／选下一步／回边落点等）；对齐第1–7课课堂应用习惯
- 整题全对建议才得分（期中简策）

### （已取消）`sentence_fill`

老师改口：**主卷无填空题**；原 `sentence_fill` 交互规格**作废**，勿实现打字空格。

## 5 服务端判分建议

1. 只认**主卷首次整卷提交**换算百分制；挑战单独首次提交记加分（每对 +2，满分 +10）。
2. 流程图多槽用 `accept`／`acceptAlternate`（若有）；无填空 `accept` 补句路径。
3. **不设达标线**；计分读 `scoring`（百分制）。`passLine`＝`null`；**禁止**加回 `passLineSuggestion`。
4. **关卡解锁与判分分离**：解锁只读作答完备性；正确率仅诊断／百分。
5. 教师接口可返回整题 `analysis`、`remixFrom`（仅师端）、逐题对错与分课细目。

## 7 无障碍与适龄

- 主卷题干尽量 ≤65 字；挑战 ≤95 字
- 颜色不作为唯一信息；连线提供文字配对反馈；站点状态除颜色外须有文字／图标态（未解锁／进行中／已通关）
- 触控热区 ≥44px；避免拖拽依赖（一律点选优先）
- 学生可见文案只用口语关名（如「分支岛」），禁止内部目标代号
